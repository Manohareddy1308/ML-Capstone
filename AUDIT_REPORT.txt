POST-AUDIT CODE FIXES (applied after initial verification)
================================================================================
The following improvements were applied to notebook source cells. Outputs in the
affected notebooks are marked as cleared; re-run those notebooks to refresh CSVs,
models, and plots.

Fix 1 - Remove redundant pipe.fit() after GridSearchCV [02_ridge_regression.ipynb, 07_random_forest_regressor.ipynb]
  GridSearchCV uses refit=True by default, so best_estimator_ is already fitted on the
  full training set. The extra pipe.fit(X_train, y_train) call after pipe = search.best_estimator_
  was redundant (harmless but misleading). Removed; notebook now goes directly from
  GridSearchCV -> y_pred = pipe.predict(X_test).
  Result: metrics unchanged (same fitted model), code is cleaner.

Fix 2 - Add max_depth=5 to DecisionTreeRegressor [06_decision_tree_regressor.ipynb]
  The unconstrained tree grew to full depth, memorising training data and producing
  R2=-0.276 on the test set. max_depth=5 balances bias-variance for ~3900 training rows.
  Re-run to obtain updated (positive) R2.

Fix 3 - Add max_depth=8 to DecisionTreeClassifier [04_decision_tree_classifier.ipynb]
  Unconstrained on 45k bank-marketing rows. max_depth=8 prevents gross overfitting while
  preserving enough depth to learn non-linear patterns.
  Re-run to obtain updated ROC-AUC (expected improvement over 0.696).

Improvement - Polynomial Regression: LinearRegression replaced with Ridge [05_polynomial_regression.ipynb]
  PolynomialFeatures(degree=2) on 12 wine features generates 91 columns including many
  noisy interaction terms. Plain LinearRegression produced R2=0.141, below even the simple
  linear baseline (0.260). Ridge(alpha=1.0) adds L2 regularisation that shrinks noisy
  coefficients and is expected to push R2 above the linear baseline.
  Re-run to obtain updated metrics.
